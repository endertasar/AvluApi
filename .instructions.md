# AvluApi API Dokumantasyon Senkron Kurali

Bu repository'de endpoint dokumani tek kaynak olarak `AvluApi/Docs/ApiReference.md` dosyasinda tutulur.
Controller, Request veya DTO degisikliginde dokuman da ayni kapsamda guncellenmelidir.

## Amac
- Kod ile API dokumani arasinda birebir uyum saglamak.
- Controller degisikliginden sonra endpoint dokumani unutulmasini engellemek.
- Dokumanda sadece gercekte var olan endpointleri tutmak.

## Ne Zaman Tetiklenir
Asagidaki dosyalarda degisiklik oldugunda bu kurallar uygulanir:
- `AvluApi/Controllers/**/*.cs`
- `AvluApi/Models/Requests/**/*.cs`
- `AvluApi/Models/DTOs/**/*.cs`

## Zorunlu Aksiyonlar
1. `AvluApi/Docs/ApiReference.md` icinde ilgili endpoint bolumunu ayni degisiklik setinde guncelle.
2. Endpoint eklendiyse yeni baslik ekle:
   - `### GET|POST|PUT|DELETE /api/...`
3. Endpoint silindiyse ilgili bolumu dokumandan kaldir.
4. Endpoint imzasi degistiyse (route, method, query, body, response) dokumani birebir esitle.
5. Yetki degistiyse `Yetki` ve `Tenant Scope` alanlarini guncelle.
6. Request/Response orneklerini ilgili Request ve DTO siniflariyla uyumlu tut.
7. TOC (Icindekiler) baglantilarini yeni basliklarla senkronize et.

## Endpoint Basina Gerekli Alanlar
Her endpoint bolumunde su alanlar bulunmalidir:
- `Aciklama`
- `Yetki`
- `Tenant Scope`
- `Request Headers`
- `Request Body` (varsa)
- `Query Parameters` (varsa)
- `Response (200/201)`
- `Response (Hata)`
- `MAUI C# Ornek Kullanim`

## Kisitlar
- Dokumanda gercekte olmayan endpointler bulunamaz.
- Oneri veya taslak endpointler endpoint listesi icine yazilamaz.
- Route yazimi controller attribute ile birebir ayni olmali (`{id:long}` gibi tip kisitlari dahil).
- Aciklamalar Turkce, JSON alan adlari kodla uyumlu kalmali.

## Kontrol Listesi
Degisiklik bitmeden once su kontrolleri yap:
- HTTP method ve route dogru mu?
- Request body alani degisti mi?
- Query parametreleri degisti mi?
- Response tipi ve ornek JSON guncel mi?
- Yetki/authorize davranisi dogru yansitildi mi?
- TOC guncel mi?
- Endpoint sayisi controllerlarla uyumlu mu?

## Cikis Beklentisi
Kod degisikligi yapan her iste, sonucta su iki seyin birlikte gelmesi beklenir:
1. Controller/DTO/Request degisikligi
2. `AvluApi/Docs/ApiReference.md` icinde ilgili endpoint dokuman guncellemesi
