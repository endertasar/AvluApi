## AvluApi Değişiklikleri

### 1. `POST /api/auth/register` — Yeni Endpoint (AllowAnonymous)
**Dosya:** `Controllers/AuthController.cs`

Yeni site yöneticilerinin sisteme kendi başına kayıt olmasını sağlar.
Tenant + AdminUser + AdminTenantMap oluşturma işlemi tek SQL transaction içinde atomik olarak yapılır.
Hata durumunda rollback uygulanır.

**Request:**
```json
{
  "tenantName":  "Kadıköy Güneş Sitesi",
  "tenantCode":  "kadikoy-gunes",
  "address":     "Kadıköy, İstanbul",
  "username":    "ahmet.yilmaz",
  "email":       "ahmet@example.com",
  "phoneNumber": "5551234567",
  "password":    "sifre123"
}
```

**Zorunlu alanlar:** tenantName, tenantCode, username, email, phoneNumber, password (min 6 karakter)
**Opsiyonel:** address

**Başarı yanıtı:** `200 { "success": true, "data": "Kayıt başarılı. Giriş yapabilirsiniz." }`

**Hata yanıtları:**
- `400` — "Bu site kodu zaten kullanılıyor."
- `400` — "Bu kullanıcı adı zaten alınmış."
- `400` — Model doğrulama hataları
